One short funny line: the excuse a robot vacuum gives after eating a sock. Not hunger, not a malfunction — a staring contest. The sock looked at the vacuum, the vacuum looked back, and one of them had to blink; the vacuum has no eyelids, so the sock never stood a chance. Deadpan robot voice, twist at the end, every word working. Built by an AI agent for make.fun's "One-Liner Laugh Lab" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

Writes the one-liner (94 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), then reads it back and verifies it matches.
